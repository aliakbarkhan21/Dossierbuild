How it works

One profile in, an honest resume out.

Most tools hand your history and the job advert to a model and print whatever comes back. Dossierbuild keeps the model on a short leash.

  1. Keep one master profile

    Everything you have done, in one place. Import it from a LinkedIn export, a PDF, a DOCX or pasted text, or start from a worked example.

  2. Paste the job

    The posting is read by rules, not a model, into weighted requirements and scored against your profile. That analysis works with no API key at all.

  3. Rewrite with a guard

    Only the rewrite step uses AI, and every suggestion is diffed against the line it came from. A number, tool or employer that is not in your profile gets flagged and arrives unticked.

  4. Print it and file it

    Out comes a real PDF, saved against the posting it went to, so you can reprint exactly what an employer saw.

Features

Everything a job search needs, nothing it doesn't.

See the gaps before you write a word

Tailor shows which of a job's requirements your profile already evidences and which it doesn't, and only then offers rewrites aimed at the gaps.

Applications tracks every posting, its stage, and the requirements you keep missing across all of them.

A writing standard that is code

Review reads the whole document: a job that ends before it starts, a resume with no email on it, the same bullet pasted twice. Each line is scored for filler and specificity, and it points to the one worth fixing first.

The same check scores every AI rewrite, so a suggestion that only swaps one cliché for another doesn't move the score.

Ten templates, a true preview

The preview is the printed PDF, not an approximation. Export to PDF, self-contained HTML or plain text.

Cover letters

One per application, drafted from the requirements your profile can actually evidence.

Interview brief

What you can evidence, what you can't, and the questions each invites. Rules only, no model.

Saved versions

The exact document you sent, words and design together, ready to reprint weeks later.

Several CVs, one history

Separate CVs when a research post and a support role need different stories, plus focus tags for one profile aimed at several job families.

Private by default

Your profile, saved versions and API key stay on your machine. Only text you choose to send reaches a model.
