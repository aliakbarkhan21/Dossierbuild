The problem

AI resume tools are fast. They also make things up.

Hand a model your history and a job advert, and it will happily give you the skills the advert asked for. That's how a resume picks up a tool you've never used, two days before the interview.

The usual approach Guesswork

  • The model reads the job advert and decides what matters
  • Rewrites borrow the advert's buzzwords as if they were yours
  • Whatever comes back goes straight onto the page
  • Nothing records what you actually sent

Dossierbuild Checked

  • The advert is read by rules, so the analysis is repeatable
  • Every rewrite is diffed against the line it came from
  • New numbers, tools or employers are flagged and left unticked
  • Each application keeps the exact version you sent
How it works

The AI suggests. Your history decides.

Only one step uses a model, and it never gets the last word.

  1. Build one master profile. Import a LinkedIn export, PDF, DOCX or pasted text.
  2. Paste a job. It's read by rules into weighted requirements and scored against your profile.
  3. Review the rewrites. Anything your profile can't back up arrives flagged and unticked.
  4. Print a real PDF. It's filed against the posting, so you can reprint exactly what they saw.

FAQ

Questions, answered plainly.

Is Dossierbuild free?

Yes. It's open source under the MIT license. You download it from GitHub and run it yourself.

Do I need an AI key?

Not to get started. Reading job postings, scoring your profile, the writing checks, every template and the PDF all work without one. An AI key is optional: a Gemini key or a Claude key adds three things, parsing an imported resume, rewriting bullets for a posting, and drafting a line on request. Every rewrite goes through the same check against your profile, whichever you use.

Where does my data go?

It stays with you. Your profile, portrait, saved versions and API key live on your own machine. The only thing that leaves is text you explicitly send to the model.

Can the AI still get something wrong?

The check catches numbers and named technologies that a rewrite added. It's a diff against your profile, not a fact-checker, so it can't tell you whether something already in your profile is true. That part stays your job.

How do I run it?

Follow the steps in the GitHub README to run it with Python, or use the included Dockerfile. It opens in your browser at localhost.
