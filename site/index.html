The whole toolkit

Everything a job search needs. Nothing it doesn't.

The analysis, the writing checks, the templates and the PDF all run on your machine without an AI key. A Gemini or Claude key adds import parsing, rewrites and line drafting.

01 · Tailor

See the gaps before you write a word.

A posting is read by rules into weighted requirements and scored against your profile, before any rewriting starts.

02 · The guard

Rewrites can't add facts.

Every AI suggestion is diffed against the line it came from. A number, tool or employer your profile doesn't contain arrives flagged and unticked, whichever provider wrote it.

03 · No key needed
0

API keys to analyse a job.

05 · Review

A writing standard that's code.

Review reads the whole document, flags filler and vague claims, and points to the line worth fixing first. The same check scores the AI's rewrites.

06 · Applications

Every posting, tracked.

Each application's stage, the exact version you sent, and the requirements you keep missing across all of them.

07 · Letters and interviews

Cover letters and interview briefs.

Letters drafted from what your profile can evidence. Briefs listing what you can and can't back up, and the questions each invites.

08 · Real job hunts

Separate CVs for different careers, focus tags for job families, saved versions and full undo.

FAQ

Questions, answered.

Still unsure? Email aliakbar@dossierbuild.lol.

Is Dossierbuild free?

Yes. It's open source under the MIT license. You download it from GitHub and run it yourself.

Do I need an AI key?

Not to get started. Reading job postings, scoring your profile, the writing checks, every template and the PDF all work without one. An AI key is optional: a Gemini key or a Claude key adds three things, parsing an imported resume, rewriting bullets for a posting, and drafting a line on request. Every rewrite goes through the same check against your profile, whichever you use.

Does the AI make things up?

It can try, which is why every rewrite is diffed against the line it came from. A number, tool or employer that isn't already in your profile is flagged, and flagged suggestions arrive unticked. Words lifted from the job advert don't count as known.

Can the check still miss something?

It catches numbers and named technologies a rewrite added. It's a diff against your profile, not a fact-checker, so it can't tell you whether something already in your profile is true. That part stays your job.

Where does my data go?

It stays with you. Your profile, portrait, saved versions and API key live on your own machine. The only thing that leaves is text you explicitly send to the model.

How do I run it?

One Docker command, at the top of the GitHub README, or the README's steps to run it with Python. Either way it opens in your browser at localhost.
